# Security policy

Version 0.1.x is the initial supported release line. No response-time SLA or
independent security certification is claimed.

Please do not post secrets or working exploits against live systems in public
issues. Use GitHub's private vulnerability reporting if enabled for this
repository; otherwise contact the repository owner through an available private
channel before sending sensitive details. If no private channel is available,
open an issue requesting one without vulnerability details.

Include affected version, a minimal synthetic reproduction, expected versus
observed behavior, and the security boundary involved. See the threat model for
trusted inputs and known exclusions. Rotate any accidentally disclosed credentials
through their issuer.
